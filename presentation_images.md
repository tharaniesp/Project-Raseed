## 🎨 Design Guidelines

### Color Palette
- **Primary Blue**: #2563eb
- **Secondary Purple**: #7c3aed
- **Accent Orange**: #f59e0b (Indian flag saffron)
- **Success Green**: #10b981
- **Warning Orange**: #f97316
- **Error Red**: #ef4444
- **Text Dark**: #1f2937
- **Text Light**: #6b7280
- **Background**: #ffffff

### Typography
- **Headings**: Modern sans-serif (Inter, Roboto)
- **Body Text**: Clean, readable font
- **Code**: Monospace for technical content
- **Hindi/Indian Languages**: Appropriate font support

### Visual Elements
- **Icons**: Lucide React style (clean, minimal)
- **Charts**: Modern, colorful data visualizations
- **Diagrams**: Clean flow charts and architecture diagrams
- **Screenshots**: High-quality, well-lit interface mockups

### Layout Principles
- **Consistency**: Same design language across all slides
- **Hierarchy**: Clear information hierarchy
- **Whitespace**: Generous use of whitespace
- **Alignment**: Consistent alignment and spacing
- **Contrast**: High contrast for readability

## 📱 Responsive Considerations
- **Desktop**: Full-featured slides with detailed information
- **Tablet**: Simplified layouts with key points
- **Mobile**: Essential information only
- **Print**: High contrast, readable when printed

## 🎯 Presentation Tips
1. **Start with Problem**: Show pain points clearly
2. **Highlight Innovation**: Emphasize Indian language support
3. **Show Real Value**: Demonstrate time savings and convenience
4. **Use Visuals**: Let images tell the story
5. **End with Action**: Clear next steps for audience
